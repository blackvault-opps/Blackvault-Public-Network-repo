## Shared interpretation

SafeVault Homebase is the primary BlackVault smart account. External wallets are optional connections. Vault AI is the workspace agent; Botpress configures agent knowledge, behavior, routes, and tool bindings. Wallet execution, live scan services, and token deployments have their own implementation records.

VLT targets Ethereum mainnet (`1`). FUN has documented Sepolia deployments (`11155111`) and a shared canonical selection still to be made. First-release asset recovery targets mainnet independently of FUN research.

Repository documentation is updated through reviewable changes. A merged document, a generated playbook, and a successful blockchain action are different milestones. The historical prototypes retain their source history; this classification does not change GitHub's archive setting.
