# FUNTOKEN (FUN)

FUNTOKEN is BlackVault Public Network's Sepolia testnet token experience.

## Network

- **Network:** Sepolia testnet
- **Chain ID:** `11155111`
- **Symbol:** `FUN`
- **Decimals:** `18`
- **Recorded deployments:** Three
- **Canonical shared application address:** Pending owner selection

## Role in BlackVault Public Network

FUNTOKEN provides an on-chain environment for:

- ERC-20 wallet interaction;
- token display and transfer interfaces;
- allowance-based interactions;
- SafeVault testnet integration;
- Vault AI blockchain discovery;
- account/delegation research; and
- ecosystem interface development.

FUNTOKEN is separate from Vault Coin. FUN's Sepolia deployment history does not represent a Vault Coin production deployment.

## Recorded Deployments

The canonical FUNTOKEN technical repository currently documents three Sepolia deployments with matching deployed runtime bytecode and an initial 20 FUN mint per deployment.

The owner has not yet selected which deployment should become the canonical shared application reference, so BlackVault application configuration should not guess one.

## SafeVault Integration

SafeVault may display and interact with the owner-confirmed canonical FUNTOKEN deployment on Sepolia as part of the testnet experience.

## Vault AI Integration

Vault AI may inspect FUNTOKEN balances, transfers, deployment transactions, contract state, and related public on-chain records through configured Sepolia providers.

## Recovery and account interpretation

A FUN balance is an existing holding, not proof of an unclaimed allocation. The recorded FUN contracts expose token functions; the deploying wallet's EIP-7702 history is a separate account capability. Initial Vault AI mainnet recovery and FUN Sepolia discovery use separate network contexts. Canonical-address selection, wallet display, and live integration remain individually recorded milestones.
