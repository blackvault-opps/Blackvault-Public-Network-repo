Client Value and Payment Model

The current framework separates each value layer by function:

BlackVault Balance — planned primary closed-loop purchase layer for eligible BlackVault and approved-partner offerings.

TON/GRAM — optional external blockchain and wallet extension.

Telegram Stars — payment rail for eligible digital goods and services purchased inside Telegram.

Vault Coin (VLT) — separate future network token, subject to testing, governance, and deployment approval.

Funding, payment processing, external-wallet connections, and token functionality will be activated only through their respective approved implementations.

Vault Coin Overview

The current Vault Coin model defines:

Name: Vault Coin

Symbol: VLT

Decimals: 18

Initial supply: 100,000,000 VLT

Lifetime cap: 420,000,000 VLT

Architecture: UUPS-upgradeable ERC-20

Governance: Owner-controlled, two-step ownership with renunciation disabled

Controls: Capped minting, burning, pausing, blacklisting, confiscation, and proxy-held asset recovery

Vault Coin has not been deployed to Sepolia or a production network. Contract implementation, testing, security records, and deployment tooling are maintained in the dedicated Vault Coin repository.

SafeVault

SafeVault is being developed as BlackVault Public Network’s self-custody wallet environment. Its intended role is to give users direct control of their supported blockchain assets while providing a future access point for Vault Coin.

The current public repository contains pre-deployment software and publication material. It does not contain production secrets, private keys, seed phrases, or signer credentials.

Review the SafeVault pre-deployment repository.
